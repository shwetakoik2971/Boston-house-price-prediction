# Experiment - House Price Prediction Using Linear Regression

## Aim

To implement House Price Prediction using Linear Regression with Python and Scikit-learn.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Linear Regression

## Dataset

California Housing Test Dataset

The dataset contains 3000 records with 9 columns, including:

- Longitude
- Latitude
- Housing Median Age
- Total Rooms
- Total Bedrooms
- Population
- Households
- Median Income
- Median House Value

## Procedure

1. Import the required Python libraries.
2. Load the California Housing dataset using Pandas.
3. Display the dataset.
4. Check the first five records.
5. Check the shape of the dataset.
6. Identify missing values.
7. Check column names and empty values.
8. Create a scatter plot between total rooms and median house value.
9. Calculate the correlation between numerical features.
10. Visualize the relationship using a correlation heatmap.

## Result

The California Housing dataset was successfully loaded and explored using Python.

The following outputs are generated:

- Dataset information and first five records.
- Dataset shape (3000 rows and 9 columns).
- Missing value analysis.
- Scatter plot of Total Rooms vs Median House Value.
- Correlation analysis of numerical features.
